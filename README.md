# Optica Medicală Florești — demo

Pitch-ready redesign demo built with React, TypeScript, Vite, Tailwind CSS v4 and Framer Motion.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Verified content

- Google Maps business name, phone, address, coordinates and opening hours
- 4.9 rating from 35 reviews
- selected verbatim Google review content
- four Google listing images stored under `public/images/`

## Replace after the owner meeting

All business content is centralized in `src/data/business.ts`. Confirm and replace:

- current service and price list
- email and WhatsApp
- available frame/lens brands
- consultation and appointment rules
- official logo and higher-quality interior/team/product photography
- real form endpoint (n8n/Supabase/Web3Forms)
